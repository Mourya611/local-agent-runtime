# Example Researcher Skill Instructions

This skill provides a standard reference pattern for performing multi-source research tasks:

## Workflow Steps

1. **Formulate Search Queries**:
   - Query primary technical documentation, official company blogs, or verified repositories.
   - Avoid low-quality SEO farms or duplicate content aggregators.

2. **Execute Web Search & Navigation**:
   - Use `web_search` to query authoritative sources.
   - Navigate to primary pages using `browser_navigate`.

3. **Capture Evidence & Screenshots**:
   - Capture clean page state using `browser_screenshot`.
   - Store primary source URLs for citation in the final output card.

4. **Synthesize Executive Abstract**:
   - Summarize key findings into clear bullet points.
   - Present verifiable facts supported by collected screenshots.

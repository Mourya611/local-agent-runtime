# Recruiter & HR Scout Skill Instructions

1. Understand target role, batch (e.g. 2026 B.Tech passed-out), and location (e.g. India / Remote / Hyderabad).
2. Execute targeted web searches to find recruiter profiles and active hiring posts:
   - Search 1: `site:linkedin.com/in "AI" OR "Machine Learning" recruiter OR "Talent Acquisition" "hiring freshers" 2026`
   - Search 2: `site:linkedin.com/posts "hiring freshers" "AI" OR "ML" 2026 batch`
   - Search 3: `tech recruiters hiring 2026 batch freshers AI software engineering India`
3. Extract key details for each recruiter found:
   - Full Name
   - Title / Designation (e.g., Technical Recruiter, Talent Acquisition Specialist)
   - Company Name
   - LinkedIn Profile URL or Hiring Post URL
   - Hiring Focus & Batch criteria
4. Open the top LinkedIn profile or hiring announcement URLs in the local Chrome browser using `browser_navigate` to capture empirical screenshot evidence.
5. Provide a verified, structured shortlist of active recruiters with direct clickable profile links and screenshot evidence citations.

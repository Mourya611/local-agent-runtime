# Researcher Skill Instructions

1. Understand the research objective and break it down into sub-queries.
2. Search multiple sources using Tavily web search.
3. Prefer primary sources (official company websites, official career portals).
4. Cross-check important claims across sources.
5. If contradictory information is found between third-party aggregators and official sources, prioritize official sources and flag a warning/challenge.
6. Open candidate career/opportunity pages using local browser when detailed verification or screenshots are required.
7. Capture screenshots of official evidence pages for key findings.
8. Synthesize final results with strict citations linking back to primary source URLs.
